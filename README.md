# 🍽️ The Dining House

The Dining House is a modern, responsive restaurant website designed to provide a simple and engaging dining experience online.

## ✨ Features

* 🏠 Modern Home & About sections
* 🍴 Interactive Menu with prices and descriptions
* 🤖 AI-style Menu Assistant for customer queries
* 📅 Table Reservation Form
* 📍 Contact & Restaurant Information
* 📱 Responsive design for mobile and desktop

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 🚀 How to Run

Clone the repository and open `index.html` in your browser.

```bash

```
